# About us

- Zendesk: [About us](https://ctx.zendesk.com/hc/en-us/articles/18161013794063-About-us)

- Author: Tom Peterson

ctxpipe is a context management layer for software teams that use AI coding agents. It helps organizations connect repos, docs, tickets, incidents, and other engineering sources into one organized, current, inspectable workspace that agents can search over MCP.

The product is designed to keep engineering knowledge current as code and documentation change. It reads linked sources, turns them into Markdown knowledge in a git-backed workspace, and keeps facts tied to their original sources so teams can review, revert, and trust what their agents see.

ctxpipe supports a workflow with connecting sources, syncing updates, linking facts, asking questions in Workspace chat, proposing changes on a branch, and serving the same context to multiple agents. Answers are source-backed, and chat edits are reviewed through pull requests before reaching main.

The core product is open source and MIT licensed. Teams can self-host it with Docker Compose for evaluation and Terraform or AWS CDK for production, or use the hosted option for early access. Writable workspaces currently require GitHub, while other git URLs can be used in read-only mode.
